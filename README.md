# Mulat Media — Campus Journalism Publication & Editorial CMS

Official digital publication platform and editorial content management system for *Mulat Media*, an active student journalism publication.

Live Site: [mulat-media.vercel.app](https://mulat-media.vercel.app/)

---

## ⚡ Tech Stack & Architecture
- **Frontend**: Semantic HTML5, Modular CSS3, Vanilla ES6+ JavaScript.
- **Backend (BaaS)**: Supabase Cloud PostgreSQL, Supabase Auth, Storage (`article-photos` bucket), and Row Level Security (RLS) policies.
- **Editorial Workflow**: Student article submission portal, editorial peer review queue, and Editor-in-Chief publishing approval.
- **Gamification**: Interactive Daily Wordle game with midnight countdown reset + Practice mode.
- **Live Metrics**: Draggable real-time visitor and like counter widget powered by Abacus API.
- **Deployment**: Vercel Edge Hosting.
