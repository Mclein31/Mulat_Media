## Implemented

- `api/newsroom.js` verifies Neon JWT signatures, issuer, audience, expiry, current account verification and ban state, and the server staff allowlist on protected requests.
- `lib/staff.cjs` owns the exact email-to-role mapping. Seven staff accounts and developer admin `mcleinonza0531@gmail.com` can access the newsroom. Only Jang Mee's verified account gets the EIC role. The developer admin can manage ordinary sections; acknowledgement changes are reserved to Jang Mee.
- Display names and browser-submitted roles/author IDs cannot grant permissions. Non-editor submissions and edits are pending review. Anonymous readers see approved articles only.
- Staff sign in with preprovisioned email/password accounts and email verification codes. Public signup is disabled and Create Account controls are removed. Password changes require the current password and a new password of at least eight characters. Old Supabase accounts and sessions are not imported. Existing Supabase accounts have not been deleted remotely.
- R2 uploads use short-lived signed PUT URLs. Account credentials stay on the server. Current upload UI supports JPG, PNG, WebP and GIF images up to 10 MB.
- Neon Auth enabled, OTP verification required, production origin allowed. The application tables in `migrations/001_neon.sql` have been created on the new, empty project. The Data API is not enabled.
